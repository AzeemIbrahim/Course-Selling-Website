# 🎓 Course Selling Website

A full-stack web application for browsing, purchasing, and managing online courses.  
Built using the **MERN** stack: React, Node.js / Express, and MongoDB, styled with Material UI.

---

## 🚀 Features implemented

- 🔐 **Secure Authentication** – Users login/register using token-based (JWT) authentication.  
- 👥 **Role-Based Routes** – Separate functionality and dashboards for Admin and User.  
- 📚 **Course Management** – Admins can create, update, and delete courses; Users can browse and purchase courses.  
- 🌐 **Notifications (Microservices Architecture)** – Messaging buses (if implemented) to trigger email or mobile notifications for relevant events.
